# Artisan project page

Project website for *Towards Physically Grounded Articulated 3D Assets: A Multi-Agent Pipeline and Benchmark*.

This branch contains the static website and its required local assets. No build step is needed.

Preview locally: `python3 -m http.server 8000`, then open `http://localhost:8000`.

GitHub Pages source: `gh-page`, root (`/`).

The page template is adapted from [Articraft](https://articraft3d.github.io/). The local Inter font license is included in `assets/fonts/Inter-LICENSE.txt`.
